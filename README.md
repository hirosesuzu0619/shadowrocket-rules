# shadowrocket-rules

存放个人使用的 Shadowrocket 模块与规则。

## modules/personal.module

个人最高优先级规则层，也就是设备上本地加载的「个人」模块。
它只做两件事：定义地区策略组，以及声明需要走代理、直连或屏蔽的域名。
因为是本地模块，任何远程模块的自动更新都不会覆盖它，所以请在 Shadowrocket 的模块列表里把它排在其他模块之上，让它的规则先被命中。

### 策略组

目前定义了两个按地区筛选的策略组，类型都是 `url-test`，会在匹配到的节点里按延迟自动择优：

- `US`：筛选名称中带有美国相关关键字的节点，例如「美国」「洛杉矶」「圣何塞」「United States」以及 `US` / `USA`。
- `TW`：筛选名称中带有台湾相关关键字的节点，例如「台湾」「台北」「高雄」「Taiwan」以及 `TW`。

筛选依据是节点名称的正则匹配，因此正则里刻意同时包含了简体、繁体和英文写法；`US` 与 `TW` 这类短缩写加了单词边界，避免误伤 `AUS` 之类的名字。
如果你的节点来自远程订阅而不是本地节点列表，可以在对应策略组末尾追加 `policy-path = 订阅链接`，让筛选作用在该订阅上。
新增其他地区时照抄同一行格式即可，只需要换组名和正则。

### 规则

规则段目前把 Siri 与 Apple 隐私中继（iCloud Private Relay）相关的域名统一指向 `US` 策略组。
书写格式为 `类型,值,策略`：精确匹配用 `DOMAIN`，后缀匹配用 `DOMAIN-SUFFIX`，关键字匹配用 `DOMAIN-KEYWORD`；策略可以填 `US`、`TW` 这类策略组名，也可以填 `DIRECT` 直连或 `REJECT` 屏蔽。
