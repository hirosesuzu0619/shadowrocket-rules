# Claude 对话导出（含上传图片）

`claude-export.js` 把 claude.ai 上的对话导出成 Markdown，并把自己上传的图片和 PDF 一起下载下来打包成 ZIP。解压后 Markdown 里的图片引用都是 `attachments/` 下的相对路径，离线、换设备或登录过期后照样能显示，整个文件夹可以直接放进 Obsidian 库。

脚本改写自 [agarwalvishal/claude-chat-exporter](https://github.com/agarwalvishal/claude-chat-exporter)（MIT 许可，原许可证见同目录 `LICENSE`）。上游通过 claude.ai 自己的内部接口读取对话，输出带 YAML frontmatter、每轮一个一级标题的 Markdown，Artifact、生成的文件和图表以代码块形式完整保留；它的缺陷是图片只写成需要登录同一账号才能加载的 claude.ai 地址。这里补上的就是这一步：生成 Markdown 之前先用同源请求逐个下载附件，再改写链接。另外加了批量导出全部历史对话的功能。claude.ai 的内容安全策略不允许页面加载外部脚本，所以 ZIP 打包器是脚本内置的，不依赖 JSZip 之类的库，整个脚本仍是单文件。

## 用法

在电脑浏览器里登录 claude.ai，按 F12 打开开发者工具，切到控制台（Console），把 `claude-export.js` 的全部内容粘贴进去回车。Chrome 第一次往控制台粘贴时会拦截，按提示输入 `allow pasting` 回车后再粘贴即可。页面右上角会出现状态框显示进度，完成后浏览器自动下载文件。

如果当前页面是某个具体对话，就只导出这一个：对话里有图片或 PDF 时下载 `<标题>.zip`，里面是 `<标题>.md` 和 `attachments/<标题>/` 目录；没有附件时直接下载 `<标题>.md`。如果当前页面不是对话（比如首页或最近对话列表），脚本会读取全部对话列表，弹窗确认后逐个导出，最后下载一个 `claude-export-<日期>.zip`，每个对话一个以创建日期开头的 `.md` 文件，附件按对话分目录存放。批量导出期间请保持页面打开，对话多时需要几分钟；单个对话出错会跳过并在控制台记下原因，不影响其他对话。

需要调整行为时，在粘贴脚本之前先在控制台执行一行设置，例如：

```js
window.claudeExportOptions = { images: 'base64' }
```

`images` 设为 `'base64'` 时图片以 data URI 直接内嵌进 Markdown，单个对话只得到一个自带图片的 `.md` 文件，缺点是文件会变大，Obsidian 里编辑也不方便；默认的 `'zip'` 是相对路径引用。`documents: false` 不下载 PDF 等文档。`mode` 可设为 `'single'` 或 `'all'` 强制指定导出方式。`delayMs` 是批量导出时两个对话之间的间隔毫秒数，默认 300，遇到限流可以调大，脚本本身也会在 429 和 5xx 时自动退避重试。

## 已知限制

图片取的是 claude.ai 提供的预览图地址，预览失败时退回缩略图，这是接口能拿到的最佳版本，分辨率可能低于原始上传文件。音频等没有下载地址的附件只保留文件名。某个附件下载失败时，Markdown 里保留原来的 claude.ai 链接，状态框会变成橙色并在控制台列出警告。`.md`、`.docx` 这类文本附件本来就以提取出的文字形式内嵌在导出结果里，不需要额外下载。对话列表接口的分页方式没有公开文档，脚本按 limit/offset 翻页并在拿不到新条目时停止，如果以后接口变化导致批量导出不完整，可以逐个打开对话用单个导出补齐。这些接口都是 claude.ai 的内部接口，改版后脚本可能需要跟着调整。
